SHOPFHS FUTURE — OPENING THE WEBSITE

1. Unzip the folder.
2. Open the ShopFHS-Future-v2 folder.
3. Double-click index.html.

The website works directly in Chrome, Safari, Edge, or Firefox. No terminal,
Node.js, npm install, or internet connection is required.

PROJECT FILES

index.html          Main website structure
css/styles.css      Full design and mobile styling
js/products.js      Product names, prices, options, and card colors
js/script.js        Search, filters, popups, customizer, and shopping bag
images/smiley.png   Original futuristic smiley artwork

CUSTOMIZATION

Names and initials cost $5. The preview supports three fonts, three colors,
and front, back, or sleeve placement. Change customFee near the top of
js/script.js if the price changes later.

PAYMENTS

This version does not process payments. Its checkout button intentionally
shows a message instead of charging a card. A secure Square connection can be
added later without rebuilding the front-end design.
